# Provenance and dependency

This release reorganizes the author's local `GBS_Hiding_Two_Routes_Lean` development into public manuscript endpoints. Lean files, directories, namespaces, and identifiers use mathematical names. The physical probability definitions are in [GBSDefinitions.lean](../LogdetLean/GramHafnian/ThreePaper/GBSDefinitions.lean).

The companion proofs come from [ComplexGramHafnians (the source version used in this release)](https://github.com/HongruZhao/ComplexGramHafnians/tree/95ab10dc594ac92207054413220ae9fd2adab08c). All 223 `LogdetLean` files of that repository and its `Challenge.lean` and `ComplexGramHafnians.lean` are included, with naming substitutions where needed. Their original hashes remain in [ANTICONCENTRATION_SNAPSHOT.json](ANTICONCENTRATION_SNAPSHOT.json). The shared source tree avoids compiling duplicate declarations. The companion `Challenge.lean` contains proposition specifications, not proof placeholders. Our own statement file is named `HidingStatement.lean` to avoid a module-name collision.

One shared hiding file, `LocalAnticoncentration/CoefficientPaperEndpoints.lean`, previously appended three unused compatibility results. This release uses the companion version without those additions, subject to the same naming substitutions. Updates to the companion are explicit source updates, not automatic pulls.

The 7 September naming revision renames 20 Lean paths and updates 206 of the 881 Lean sources. [MODULE_RENAMING.json](MODULE_RENAMING.json) records the previous commit, exact text substitutions, original and current paths, and both hashes for every Lean file. For the version 1.1.0 baseline, the source audit checks each source hash, reverses the recorded substitutions, and checks the restored original hash. The version 1.2.0 extension is separately recorded below. For all 225 companion files it also checks that restored hash against the separately pinned upstream snapshot. Thus the included sources are identical to their recorded originals **after reversing the naming substitutions**; byte-for-byte identity before that reversal is not claimed. The upstream companion repository itself is not modified. Historical receipts and the renaming record retain the earlier names as provenance.

The Route 1 proof imports `ComplexGramHafnians` and calls its public `theorem2_1`. Source vendoring preserves the companion implementation under the recorded renaming independently of subsequent repository changes. This is not a separate Lake git dependency or submodule.

The earlier A2 source-attribution revision of 2026-09-07 replaced the former Helgason/Chen attribution with the published FitzGerald–Warren flat Takagi Jacobian and the An–Wang–Yan measurable integration theorem. That revision changed the A2 source comments and documentation without changing its declaration, definitions, proof terms, or the pinned companion sources.

The subsequent Appendix A alignment uses the same four-part structure for A1–A4 in [AXIOMS.md](AXIOMS.md): mathematical translation of the Lean axiom, source statement, justification of differences, and notation correspondence. [A2_SOURCE_DERIVATION.md](A2_SOURCE_DERIVATION.md) supplies the full A2 justification, including the one-sheeted ordered Takagi map, volume and chamber factors, and the concrete globally measurable selector. A3 spells out its coordinate map on singular samples; A4 states its supplied-law premise and the exact inverse-Gram/zonal coefficient conversion. That earlier documentation-only stage preserved all Lean files. The later naming revision changes module and identifier names and has its own execution evidence in [the verification status](../verification/STATUS.md). Historical build and axiom receipts retain their original source-snapshot meaning.

## Theorem 2.1 and Corollary 2.2 in version 1.2.0

The version 1.2.0 sources shared by GitHub and Zenodo are based on the [UniformHiding snapshot used for version 1.1.0](https://github.com/HongruZhao/UniformHiding/tree/db6d9e254a127a2ad9d1bab9126a0d81e1f8d853). It changes exactly three Lean files: `HidingStatement.lean`, `UniformHiding.lean`, and `HidingVerification.lean`. These are mathematical additions, not naming substitutions. Theorem 2.1 now includes all positive input counts, and Corollary 2.2 is its direct quantitative specialization. The GitHub clone and the Zenodo package use the same revised statements and proofs.

[COROLLARY22_RELEASE.json](COROLLARY22_RELEASE.json) records the new hashes and the exact preceding text of those three files. The portable audit checks their current hashes, checks the saved preceding text against the independently recorded version 1.1.0 hashes, and applies the historical reverse-renaming check to that preceding text. For all other 878 Lean files, the unchanged-source and historical restoration checks apply directly. All 225 companion files remain unchanged from version 1.1.0 and are checked against their pinned upstream originals after reversing the prior naming substitutions.

This provenance check distinguishes new proofs from the baseline; it does not prove that the new statements are correct. The new build and exact dependency audit are recorded separately in [verification/STATUS.md](../verification/STATUS.md). No assumption file or imported companion file was changed.

The independent statement/proof/check organization is inspired by [PrimeGaps186](https://github.com/openai/PrimeGaps186). We do not claim its comparator or independent kernel-checker runs. The build log and axiom report state exactly what was executed for this release.
